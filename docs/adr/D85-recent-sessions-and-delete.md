# D85. 侧栏的最近会话块与直接删除

- **取代**：无

## 背景

读者每天在同一批会话之间来回：它们散在宿主的工作区分组里，跨工作区时要点开分组才找得到。宿主只允许置顶，而置顶是长期收藏，不是「今天在做的这些」。同一处还缺一个动作：宿主的会话菜单只归档，归档只是把行从列表里挪走，记录仍在本机；读者想直接删掉一条不再需要的会话时，没有入口。

## 决定

- 侧栏新增「最近 24 小时」一块，默认排在最上面：宿主工作区分组之前、置顶汇总之前。列出最近一天内有过动静（`updatedAt` 在窗口内）的会话，新的在上，最多十条；归档的、宿主从未提问过的占位行与子代理子会话不进入。块只读取宿主的两份列表（`sessions.list`、`workspaces.list`）与状态图，行上的圆点、标题、工作区名与宿主的会话菜单都取自宿主自己。
- 块的位置固定在最上面，不提供位置选项：读者要的是打开就先看到今天的会话。
- 每一行多一个删除动作，排在宿主的会话菜单按钮之前：按下先弹本插件自己的确认卡（写明会话名与不可恢复），确认后 `POST /dsh-deepcraft/session-delete` 交给宿主半边删除本机的会话目录并从归档集合里移除；宿主仍打开着的会话由该路由以 409 拒绝，卡上说明先关闭。删除成功后该行立刻从本块消失，宿主列表在重扫后自行更新。
- 置顶汇总与宿主的会话行不提供删除：置顶由宿主自己的菜单维护，直接删除一条仍被置顶的会话会给宿主留下悬空的置顶项。
- 这一块跟随偏好 `recentSessions` 开关（默认开），关掉即整块撤走；开关与其他功能开关一样实时生效（D84 的偏好表）。
- 行的外观与置顶汇总同一份（`shared/session-block.ts` 与 `shared/session-block.css`）：两个块只各自给出要画的 id 与标题，挂载、订阅、绘制与拆除只写一次。

## 后果

- 侧栏顶部多出一块随当天活动变化的列表；忙碌的一天里最多十条，其余仍在宿主的分组里。
- 删除是不可恢复的本机操作，确认卡是唯一的拦截；宿主打开中的会话无法删除，提示读者先关闭。
- 宿主列表与本地隐藏之间有一个短暂的不一致：删除后本块立即隐藏该行，宿主自己的分组在重扫前仍可能显示它，直到宿主刷新列表。
- 依赖宿主的 `updatedAt`、归档集合与 `sessions.list` 的形状（D3 的契约表）；宿主改名或改形时由契约检查先报出来。

## 重审条件

- 宿主提供会话删除与最近列表的官方接口时，改为调用接口并删掉本插件的删除路由与这一块的自绘。
- 宿主自己在侧栏提供「最近」分组或删除动作时，删掉对应的那一半。
