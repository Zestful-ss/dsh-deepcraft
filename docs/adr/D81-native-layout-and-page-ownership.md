# D81. 宿主布局与整页让位

- **取代**：D70、D71、D74、D49、D23、D32、D55、D56、D57、D58、D63

## 背景

这套皮肤早先照着宿主界面重画了一批区域：顶部的标签条、Windows 的标题带、侧栏的搜索框与账号行、对话里的统计、轮次导航、等待行，还从上游聊天插件搬来了折叠、跟随、文件操作行与过程摘要。每一处重画都是对宿主结构的一次复制：宿主调整一次标记、类名或排列，复制品就失灵一次，皮肤要跟着改一次；读者装上新版宿主时先看到的是这些复制品，而不是宿主自己的修复。真正只有皮肤能给的，是配色、字体、品牌标志与宠物，这些读取宿主的令牌，宿主改版时不需要重写。

同时另一个问题早已有答案：一页上可能同时坐着另一个皮肤，或 ds-bot 的 Bot 外壳。谁在画这一页必须先有唯一答案，共存才不会变成逐条避让。

## 决定

- 皮肤只改颜色与字体。宿主控件的几何、位置、间距、边框形状、动效、滚动跟随与过渡都取宿主自己的值；皮肤样式表不写这些布局的替代数值，也不重画宿主的按钮、标签、滚动条与选中文字。
- 保留的外观能力：深海蓝、暖橙、森林绿三套配色与「跟随宿主」，主题字体与「跟随宿主」，读者自己的品牌名称、标志图、文字标志与强调色，聊天框宠物及其选择与导入，跨工作区的置顶会话汇总，以及右侧面板引导页在内容过多时可滚动的修正。
- 保留两个子代理设置：会话级的子代理路由选择，以及输入区模型槽位旁的胶囊选择器；它们读取宿主的模型菜单，不改写它的排列。
- 页面属主只在唯一一处判定：另一个皮肤作画、或另一个插件的外壳挂在页面上，即为让路；皮肤优先，两者同时在时页面归皮肤。判定在启动时同步读一次，之后跟随两处标记的真实变化，不跨变化缓存。
- 让路的粒度是整页：不挂本主题的样式表、不装本主题的任何功能、不写本主题的标记、不留本主题的任何界面，设置页一并交出。换回本主题的入口由占着页面的那个插件自己提供；ds-bot 的 Bot 面是唯一例外，它在让路期间保留一个返回本主题的按钮，范围、位置与按下后的行为见 D82。让路只收掉视觉，功能的拆除不牵连读者存下的设置与偏好；抢回页面时重新采用偏好、挂样式表、装齐功能，已在安装的功能不重复安装。
- 搬来的聊天区交互整体退场：折叠与折叠动画、滚动跟随与流式位移、等待状态行、过程摘要、文件操作行的重绘与合并、轮次导航、对话统计的改造、新会话首页的水波纹背景、对话页眉下方的渐隐、标签条的重绘、标题进入顶栏、「聊天 / 代码」切换按钮、侧栏账号行与搜索，都由宿主自己的界面承担。它们写过的偏好留在存储里，皮肤不读、不改写。
- 说明模型正在做什么的那一行由宿主给出；皮肤不再从推理正文里推断从句，也不为此发请求。
- 其他插件未标记的样式表仍由本包在到达时接管，宿主自己的簿记不会把它们当作本包的表删掉。

## 后果

- 宿主界面的改版不再与皮肤的重绘冲突，外观只剩颜色与字体两层；代价是皮肤不再提供宿主没有的界面能力，读者从别的插件那里找它们。
- 让路期间整页惰性，页面上的本包行为全部停摆，读者打不开本主题的设置页，偏好要等本主题拿回页面之后才能改；翻转会带来一次可见的重新挂载。
- 让路判定依赖 ds-bot 未承诺的标记与本地存储键；它的浏览器半边没能运行时，存下的模式会让本主题一直让路。
- 旧偏好留在读者的配置里且无人读取，设置页不再显示它们，也没有迁移去清除。
- 端到端检查按真实宿主控件的可用性与配色、字体的切换判定，皮肤重画的区域不再有专用场景。

## 重审条件

- 宿主为主题插件提供只覆盖颜色与字体的扩展点，或公开页面属主与界面模式的读写接口时，让路判定与界面切换改为依赖而不读取标记。
- ds-bot 公开自己模式的读写接口时，删掉对它存储键与菜单次序的依赖。
- 读者需要被删掉的某项界面能力，而宿主仍不提供时，另写一条决策说明接回的范围。
