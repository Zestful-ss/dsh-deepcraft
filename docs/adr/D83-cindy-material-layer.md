# D83. Cindy 配色的材质层

## 背景

D81 把皮肤的改动收在颜色与字体两层：宿主的圆角、阴影、动效与栏位几何都取宿主自己的值。读者要求把 Cindy 的整套视觉体系搬进来，而 Cindy 的外观不只有色板：它固定 4 / 8 / 12px 圆角、去掉阴影、把动效压到 150 / 200 / 250ms，并用一层半透明侧栏和背后环境光表现「液态玻璃」。这些值不在配色表里，落在 D81 的边界之外。

## 决定

- Cindy 以**一套可选配色**出现：`cindy` 进入配色表，浅色为暖象牙、深色为中性近黑。选中它时，同一份配色还启用这一条材质层。
- 材质层只写宿主已经公开的 token：`--dsw-radius-*`、`--dsw-shadow-lv*`、`--dsw-elevation-*`、`--ds-transition-duration*`、焦点环、滚动条、diff、tooltip 与 toast。颜色值在 `tokens.json` 的 `cindy` 列；形状与动效在 `theme/cindy.css`，两者都由配色门控制。
- 侧栏玻璃使用 `layout-frame`、`sidebar-column`、`sidebar-root` 三个 part，不读宿主哈希类名。模糊挂在 `::before` 伪元素上，避免 `backdrop-filter` 把宿主的 fixed 收起按钮变成侧栏内的定位元素。环境光只铺在 `body` 背景上。
- 不迁移 Cindy 的导航折叠按钮、侧栏紧凑化与行高改写：它们改宿主结构或几何，超出这一层，也破坏 D81 的宿主布局承诺。宿主自己的收起入口保持原位置与原行为。
- 选择其他配色时这一层整体退出，圆角、阴影、动效和侧栏恢复宿主值；不写 inline style，不注入结构，不持有全局监听。
- 字体仍是三个独立角色，Cindy 配色不自动改字体；要贴近 Cindy，界面字体选 Inter，正文跟随界面。

## 后果

- 选中 Cindy 时，皮肤不再只改颜色与字体：它还会改宿主的圆角、阴影、动效与侧栏材质。这是 D81 的一处明确例外，范围仅限这一个配色。
- 侧栏玻璃依赖宿主的 part 标记与 `backdrop-filter`；模糊在低端机器上有 GPU 成本，壁纸插件的透明画布可能让环境光更明显。
- 不迁移折叠与紧凑化，Cindy 的侧栏空间收益不会出现；这是保留宿主可恢复入口与几何的代价。
- 端到端配色场景与 smoke 覆盖 Cindy 的浅色、深色、强调色与玻璃层；宿主改名或移除 part 时由契约检查先报出来。

## 重审条件

- 宿主把圆角、阴影或动效纳入主题扩展点，材质层改为只读该扩展点。
- 宿主为侧栏提供原生材质或背景接口，删掉环境光与伪元素模糊。
- Cindy 的设计体系改版，或读者不再需要这套配色时，连同 `cindy.css` 和配色列一起删除。
