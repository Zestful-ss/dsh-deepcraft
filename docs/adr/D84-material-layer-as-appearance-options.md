# D84. 材质层是与配色无关的外观选项

- **取代**：D83

## 背景

D83 把 Cindy 的设计体系收进一套可选配色：选中 `cindy` 时连同它的圆角、零阴影、动效时长与侧栏玻璃一起生效。读者的本意并非再出一套配色——Cindy 是被借鉴的参考主题，值得留下的是它那套**功能**：圆角档位、平铺阴影、克制动效、玻璃侧栏与环境光。这些能力与色板无关，任何配色下都可能想要；把它们绑在 `cindy` 这一列上，等于让读者为了形状去换掉整套颜色。

## 决定

- **删除 `cindy` 配色**。皮肤配色回到深海蓝、暖橙、森林绿与跟随宿主；已存 `cindy` 的配置迁移到暖橙，材质默认值让人看到的样子不变。
- 材质层成为外观页自己的选项，与配色正交，出厂即 Cindy 的取值：
  - 圆角：Cindy 档（4 / 8 / 12px）或宿主；
  - 阴影：平铺（去掉三级阴影，抬升改画描边）或宿主；
  - 动效：Cindy 节奏（150 / 200 / 250ms）或宿主；
  - 玻璃侧栏：半透明底、42px 模糊与内描边，或关闭；
  - 环境光：整窗背景的暖橙、蓝、粉三层径向光，或关闭。
- 材质层只写宿主已公开的 token（`--dsw-radius-*`、`--dsw-shadow-lv*`、`--dsw-elevation-*`、`--ds-transition-duration*`）与 `layout-frame`、`sidebar-column`、`sidebar-root` 三个 part；不写 inline style，不注入结构，不持有全局监听。模糊挂在伪元素上，宿主的 fixed 收起按钮不因此改变定位。
- 配色自己的别名（焦点环、行内代码、引文、diff、tooltip、toast、滚动条、开关滑块）留在配色表里，材质层不重画它们：形状可以借用，色板的身份不被改写。
- 布局几何仍归宿主（D81）：行高、间距、排列、导航折叠与侧栏紧凑化都不进入材质层。D84 修订 D81 的「形状」一半——形状语言成为皮肤选项、出厂取 Cindy 的值，而布局保持原生。

## 后果

- 出厂页面不再是宿主的圆角与阴影：12px 圆角、平铺阴影、250ms 动效、玻璃侧栏与环境光成为默认外观，读者逐项关掉即可回到宿主形状。外观快照与配色场景因此按新默认重读。
- 玻璃侧栏有 GPU 成本；壁纸的透明画布会让环境光更明显，两者都在低端机器上可感知。
- 视觉组合从「一组配色」变成「配色 × 材质」两维；外观走查要覆盖出厂默认与每个材质开关的关闭态。
- `cindy` 从配色表、令牌表与配色场景中删除；文档与 CHANGELOG 同步。

## 重审条件

- 宿主把圆角、阴影或动效纳入主题扩展点，材质层改为只读该扩展点。
- 宿主为侧栏提供原生材质或背景接口，删掉环境光与伪元素模糊。
- 参考主题的设计体系改版，或读者不再需要这套材质时，调整取值或整体删除。
